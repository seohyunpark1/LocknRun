# Partner logos

Put the official logo files here, with exactly these names, and they appear in the
"Powered by" strip on the home page the "Sponsored by" card at the top of the home page, and the "Built on Solana" box in the web sidebar (until then, the names are shown as text):

- `solana.svg`      (Solana brand assets)
- `usdc.svg`        (Circle's USDC brand kit)
- `strava.svg`      (Strava brand guidelines: use their official "Powered by Strava" logo)

Use the versions each company publishes for partners, and follow their brand guidelines.
PNG works too: change the file extension in `PARTNERS` in `lib/config.ts`.

To add more app sponsors to the "Sponsored by" card, add a line to `APP_SPONSORS` in `lib/config.ts`.
