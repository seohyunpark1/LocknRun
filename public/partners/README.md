# Partner logos

The app shows each partner's logo automatically by loading the company's own site icon from its domain
(see `PARTNERS` in `lib/config.ts`: Solana, Circle, QuickNode, Strava).

For sharper, full logos, drop the official files here with these names and they're used instead:

- `solana.svg`     (Solana brand assets)
- `circle.svg`     (Circle brand / press kit)
- `quicknode.svg`  (QuickNode brand / press kit)
- `strava.svg`     (Strava brand guidelines: use their official "Powered by Strava" logo for the Strava import)

To add another partner, add a line to `PARTNERS` in `lib/config.ts`.
